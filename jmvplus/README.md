# jmvplus

`jmvplus` extends jamovi's built-in Descriptives analysis with the coefficient
of variation (CV), reported as a percentage when `Std. deviation` is selected.

It also adds a pink 95% prediction interval to linear scatterplots when `Show
line` and `Confidence interval` are selected.

It also adds the classical Fisher-Snedecor F-test to the Independent Samples
T-Test, shown in its own table right below Levene's test when `Homogeneity
test` is selected.
